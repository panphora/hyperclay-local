# Stability

These are the commitments that do not change. They are written down so nobody has to trust our intentions, only our text.

**Shipped versions keep their licenses, forever.** Every version released under MIT stays MIT. Every version released under MIT-0 stays MIT-0. The last MIT release of each fenced package stays tagged and usable forever. Relicensing only ever applies forward, to new versions.

**Each version's terms are locked at its release.** A Clay-licensed version's terms, including its MIT Conversion Date, are fixed in its LICENSE file the day it ships and never change. Future versions may ship under revised terms; revised terms apply only to those future versions, never retroactively.

**Every Clay-licensed version becomes plain MIT on a printed date.** The conversion is automatic, unconditional, and irrevocable, and binds our successors and assigns. The window is 18 months per version today, and for future versions it will never exceed 24 months.

**Nobody is ever stranded on abandoned code.** If we go 12 consecutive months with no public release of a package and no security response to a responsibly reported vulnerability in it, or cease operations without a successor that assumes the license, every Clay-licensed version of that package becomes MIT immediately. This is written into the license itself, not just here.

**ClayJS and the page layer are MIT-0, forever.** Everything that runs inside or alongside your HTML files, ClayJS and the in-page libraries, is MIT No Attribution: use it, copy it, remix it, ship it, no conditions, never fenced.

**The file format belongs to everyone.** The malleable HTML file specification is CC0, and "malleable HTML" is a generic term that nobody, including us, will ever register or own.

**Is this open source? Not by the OSD, and we will not blur that.** The fenced software is source available: the source is public, you can read every line, build from it, modify it, and self-host it. It becomes open source, plain MIT, on the printed date, per version.

**One contingency, stated now so it never surprises anyone.** A genuinely free standalone clone owes nothing under the Clay License, and we accept that. If a rebranded free host ever reaches serious scale, a narrow zero-price clause exists in a drawer and would ship only in a future major version, never retroactively. Nothing already shipped ever changes, under this or any other contingency.
